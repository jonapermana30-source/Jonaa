# JONA SHOP

Website toko online demo untuk presentasi.

## Menjalankan di komputer
Buka file `index.html` menggunakan browser.

## Upload ke GitHub Pages
1. Login ke GitHub dan buat repository baru, misalnya `jona-shop`.
2. Upload `index.html` ke repository (pastikan berada di folder utama/root).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses selesai. GitHub akan menampilkan alamat website di halaman Pages.

## Catatan
- Keranjang dan checkout berfungsi sebagai simulasi presentasi.
- Tidak ada pembayaran, database, atau penyimpanan pesanan sungguhan.
- Foto produk diambil dari URL Unsplash, jadi perlu koneksi internet agar tampil.
